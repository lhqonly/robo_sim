# MuJoCo models

Each subdirectory will contain human-readable MuJoCo XML for one learning stage:

- `single_joint/`: fixed base, hinge and one link
- `pendulum/`: gravity-loaded knee-like pendulum
- `leg_2d/`: hip, knee and ankle chain
- `exoskeleton/`: simplified assistive actuators

Phase 1 已在 `single_joint/single_joint.xml` 中实现第一个物理模型。其余目录仍是后续阶段的占位结构。
