# Experiment 001：单关节恒力矩与 PD 控制

## 目标

逐步验证机器人/外骨骼的最小控制链路：Phase 1 由 Python 写入恒定 motor 力矩并观察运动；Phase 2 读取关节位置/速度作为反馈，用 PD 控制器实时改变力矩；Phase 2.5 再加入可开关的重力补偿，比较“纯 PD”和“先托住重量再纠偏”。

## 模型

- 固定基座
- 一个绕 Y 轴旋转的 hinge joint
- 0.5 m、1 kg 的杆件
- 力矩范围 `[-2, 2] N·m` 的 motor actuator
- 仿真时间步长 `0.002 s`，包含重力和关节阻尼
- 蓝色基座和黄色电机外壳只用于显示，不参与碰撞；避免它们与从同一转轴出发的橙色杆产生非物理自碰撞。

## 运行

### Phase 2 / 2.5：PD 与重力补偿（当前建议）

打开 3D Viewer 和中文网页动态响应曲线：

```bash
cd ~/robo_sim
source .venv/bin/activate
python experiments/001_single_joint_pd/run.py \
  --mode pd --view --target-deg 45 --kp 5 --kd 3 \
  --gravity-compensation
```

这个命令默认开启重力补偿，适合测量从 `0°` 到 `45°` 的响应时间。若要重温纯 PD 的静态误差，可把目标改为 `30°`，关闭重力补偿，观察杆停在约 `20.27°`；再开启补偿，应看到杆继续运动到接近 `30°`。响应曲线只在网页中实时显示，不再生成静态 PNG。网页会保留最近 30 秒数据，因此同一张图可以直接比较开关前后的角度和力矩。

如果网页提示“仿真现在是暂停状态”或曲线不动，请在 MuJoCo Viewer 左侧 `Simulation` 区域点击 `Run`；网页暂停记录和 MuJoCo 暂停仿真是两个不同开关。

只想快速运行数值验证、不打开窗口时：

```bash
python experiments/001_single_joint_pd/run.py \
  --mode pd --target-deg 30 --kp 30 --kd 3 \
  --duration 3 --samples 7
```

中文面板可以在 Viewer 运行时精确修改目标角度、`Kp`、`Kd` 和重力补偿开关。PD 模式下，原生 Viewer 右侧紫色 `joint_motor` 不再是手动输入，而是控制器每个时间步算出的总输出；即使拖动，也会立即被控制器覆盖。

建议在中文面板依次尝试：

- `Kp=8, Kd=1`：拉向目标较弱，最终误差更大。
- `Kp=30, Kd=0.2`：阻尼较弱。
- `Kp=30, Kd=3`：当前模型下较平衡。
- `Kp=30, Kd=20`：阻尼很强，接近目标更慢。

### Phase 1：恒力矩开环（保留用于对照）

```bash
cd ~/robo_sim
source .venv/bin/activate
python experiments/001_single_joint_pd/run.py \
  --mode torque --torque 0.5 --duration 1.0 --samples 6
```

当前 WSL 支持 WSLg 时，可打开 MuJoCo Viewer 实时观察：

```bash
python experiments/001_single_joint_pd/run.py \
  --mode torque --view --torque 1.0
```

Viewer 中蓝色方块是固定基座，黄色圆柱是简化的关节/电机位置，橙色杆是运动连杆。拖动鼠标可以旋转视角，滚轮可以缩放。GUI 会一直运行，关闭 Viewer 窗口或先点击终端再按 `Ctrl+C` 才退出。GUI 在隔离的子进程中运行，因此其原生窗口清理不会占住终端。

同时会自动打开一个浏览器中文学习面板。它只监听本机 `127.0.0.1`，关闭 Viewer 或按 `Ctrl+C` 后服务随即停止。

### 中文学习面板

原生 Viewer 的 `Watch.Field` 是自由文本，原生 `joint_motor` 也是只有滑块的固定控件；Python Viewer API 不能直接把它们替换为自定义控件。因此项目增加了一个与同一份 MuJoCo `data` 实时同步的辅助面板。

共同功能：

- Watch 下拉框：`qpos` 同时显示 `rad / degree`，`qvel` 同时显示 `rad/s / degree/s`；还可观察 `ctrl`（指令扭矩）和 `actuator_force`（实际输出）。
- 每个字段显示中文含义、单位和实时值。
- 重置按钮：恢复初始姿态。

`--mode torque` 时显示：

- 精确扭矩输入框：可键入例如 `1.234`，按 Enter 或点击“应用精确值”。
- 快速滑块与 `-2/-1/-0.5/0/+0.5/+1/+2` 预设按钮。

`--mode pd` 时显示：

- 目标角度（度）、比例增益 `Kp`、微分增益 `Kd` 的精确输入。
- 重力补偿开关：关闭时是纯 PD，开启时先托住杆的重量再由 PD 纠偏。
- 当前误差、PD 力矩、重力补偿力矩、限幅前总力矩，以及是否触及执行器上限。
- “为什么没有完全到达目标”解释卡：同时显示目标姿态保持力矩、当前位置重力/偏置矩、P 项和 D 项。
- 最近 30 秒的三张实时响应曲线：目标/实际角度、角速度、PD/重力补偿/实际总力矩；支持暂停记录和清空。
- 响应时间测量：首次到达、10%～90% 上升时间、稳定时间、确认稳定耗时、最大超调和当前误差。
- 稳定判据输入：默认误差 `±1°` 且连续保持 `0.5 s`；黄色曲线表示目标上下的允许范围。
- 不显示 `joint_motor` 手动输入。PD 模式的力矩由控制器自动计算，用户只需要修改目标角度、`Kp` 和 `Kd`。

恒扭矩模式下，原生 Viewer 的紫色 Control 和中文面板控制同一个 `data.ctrl[0]`。PD 模式下，它们仍显示同一个值，但该值是控制器输出；需要在中文面板修改目标或增益，而不是拖动紫色滑块。

如果浏览器没有自动打开，复制终端输出，例如：

```text
Chinese learning panel: http://127.0.0.1:53017/
```

也可以禁止自动打开浏览器：

```bash
python experiments/001_single_joint_pd/run.py \
  --view --torque 1.0 --no-browser
```

参数：

- `--mode`：`torque` 为 Phase 1 开环，`pd` 为 Phase 2 闭环；默认保持 `torque` 以兼容旧命令。
- `--torque`：恒定电机力矩，单位 N·m，允许范围 `[-2, 2]`。
- `--target-deg`：PD 目标角度，单位 degree，关节范围约 `[-120°, 120°]`。
- `--kp` / `--kd`：PD 比例/微分增益，必须非负。
- `--gravity-compensation`：在启动时默认开启重力补偿；Viewer 中仍可随时切换。
- `--settling-tolerance-deg`：稳态允许误差，默认 `1°`。
- `--settling-hold-s`：进入误差范围后必须连续保持多久，默认 `0.5 s`。
- `--duration`：无窗口模式的仿真时间，单位 s，必须大于 0。
- `--samples`：无窗口模式打印多少个等间隔状态，至少为 2。
- `--view`：打开交互式 GUI，忽略 `--duration/--samples`，直到人工退出；不加时采用无窗口快速运行。
- `--no-browser`：仍启动中文学习面板服务，但不自动打开浏览器。

## 为什么做这个实验

它验证的不是“外骨骼已经能帮助人走路”，而是后续所有控制的最小基础是否正确：

1. XML 中的固定端、活动杆和旋转轴是否装配正确。
2. Python 发出的正/负电机力矩是否进入了预期关节。
3. MuJoCo 计算出的角度和速度方向是否符合直觉。
4. 重力、惯性和阻尼能否共同产生稳定、可解释的运动。

以 `1 N·m` 为例，电机始终输出同一个力矩。它不是命令关节“转到 1 rad”。杆长 0.5 m、质量 1 kg，质心距关节约 0.25 m；静止时满足：

```text
电机力矩 = 重力力矩
1 ≈ 1 × 9.81 × 0.25 × sin(angle)
angle ≈ 0.420 rad ≈ 24.1°
```

所以杆件先转动，阻尼逐渐消耗速度，最后停在约 24°。终端中接近 `0.419982 rad` 的结果正好验证了这个力矩平衡。

本实验还不能验证真实膝关节精度、人体舒适性、硬件电机性能或外骨骼助力效果；这些需要后续模型和真实数据。

## 如何读结果

### Phase 2 响应曲线

三行图从上到下分别表示：

1. 目标角度与实际角度：两条线越接近，跟踪误差越小。
2. 角速度：接近 `0` 表示关节逐渐稳定；正负反复变化通常意味着振荡。
3. 控制力矩：紫色是 `P + D`，绿色是重力补偿，橙色是二者相加并经过 `[-2, 2] N·m` 限幅后真正施加的总力矩。

例如 `Kp=5`、`Kd=3` 时，纯 PD 最终约到达 `20.27°`，而不是恰好 `30°`。原因是杆件受重力作用：速度为零后 D 项消失，纯 PD 必须保留约 `9.73°` 的位置误差，才能让 P 项继续产生托住杆件的力矩。这叫静态误差。开启重力补偿后，补偿项在 30° 持续提供约 `1.226 N·m`，PD 可以在误差接近 0 时基本不出力。

例如设置目标 `-45°`、`Kp=5`、`Kd=3`：保持在 `-45°` 需要约 `-1.734 N·m`，虽然没有超过电机的 `-2 N·m` 下限，但纯 PD 在目标处的误差为 0，因此输出也会变成 0。最终会停在约 `-30.7°`，此时约 `-14.3°` 的误差通过 `Kp` 产生约 `-1.25 N·m`，恰好抵消当前位置的重力矩。提高 `Kp` 能缩小这个误差；开启重力补偿则能在较小 `Kp` 下直接补上已知的重量负担。

Viewer 运行时，实时曲线就在中文面板的状态卡下方。修改目标角度后，不要清空曲线：绿色目标线会出现阶跃，蓝色实际角度线随后追踪过去，这就是最直观的闭环响应实验。关闭 Viewer 后这些临时曲线随页面一起结束，不生成静态图片。

### 如何用响应时间调参

推荐先固定目标、重力补偿和稳定标准，例如目标 `45°`、开启重力补偿、误差 `±1°`、连续保持 `0.5 s`。每组参数都按下面的相同步骤比较：

1. 在曲线左侧输入目标、`Kp/Kd` 和稳定判据。
2. 点击蓝色“应用参数并从 0° 开始测试”。
3. 等待页面显示“已确认稳定”。
4. 同时记录稳定时间、最大超调、曲线是否振荡以及力矩是否长时间触及 `±2 N·m`。

“只应用，不重置姿态”用于在线观察参数变化，不保证形成完整的 `0° → 目标` 阶跃。重复应用相同目标不会再清除上一轮有效计时；要公平比较两组参数，应始终使用蓝色一键测试按钮。

当前模型中 `Kp=5`、`Kd=3`、目标 `45°`、开启重力补偿时，上升时间约 `1.314 s`，首次到达与稳定时间约 `2.316 s`，到 `2.816 s` 才完成连续 `0.5 s` 的稳定确认，最大超调约 `0°`。

同一理想模型、同一目标和判据的示例对比：

| Kp | Kd | 上升时间 | 首次到达 | 稳定时间 | 最大超调 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 5 | 3 | 1.314 s | 2.316 s | 2.316 s | 0° |
| 20 | 0.2 | 0.224 s | 0.334 s | 2.480 s | 10.843° |
| 20 | 3 | 0.324 s | 0.590 s | 0.590 s | 0° |

第二组虽然第一次到达最快，但因为 `Kd` 太小，冲过目标约 `10.8°` 并继续振荡，真正稳定反而最慢。这说明“首次到达快”不等于“控制得好”。

### 如何看“外骨骼调参体检”

响应时间下方增加了一组固定 `3 s` 评价窗口的指标。固定窗口很重要：如果一组统计 1 秒、另一组统计 3 秒，RMSE、能量和限幅占比就不能公平比较。

- **角度误差 RMSE**：3 秒内总体偏离目标的典型大小，越小越准。
- **累计绝对误差 IAE**：把每一瞬间“还差多少”累加，越小表示又快又准。
- **峰值角速度**：最快转了多快；过高时人体更可能感到动作突然。
- **峰值角加速度**：速度增加得有多猛。
- **峰值 jerk**：加速度变化得有多突然，是动作平滑度/冲击感的提示量。
- **峰值力矩和限幅时间**：电机最大用了多大力，以及在 `±2 N·m` 上“踩满油门”多久。
- **累计机械功 `|τ·ω|`**：这一动作中执行器输出机械能量的近似负担。

相同目标 `45°`、`Kd=3`、开启重力补偿的当前模型对比：

| Kp | 稳定时间 | 3 s RMSE | 峰值速度 | 峰值 jerk | 限幅时间 / 占比 | 机械功 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 5 | 2.316 s | 15.11° | 63.6°/s | 34,882°/s³ | 0.032 s / 1.1% | 0.781 J |
| 20 | 0.590 s | 10.66° | 165.6°/s | 47,653°/s³ | 0.184 s / 6.1% | 0.938 J |

这组数据把肉眼不容易看出的代价显示出来：`Kp=20` 更快、更准，但峰值速度约为原来的 2.6 倍，jerk 更高，电机顶住限幅的时间约为原来的 5.8 倍。

这些指标用于同模型、同目标、同负载下比较参数，不是人体安全阈值。NIST 的外骨骼评价综述强调还要结合任务效率、人体运动学/动力学、舒适度等维度；人体交互力矩、绑带压力、步态相位差和代谢成本需要人体模型或真实传感器后才能评价。参考：[NIST 外骨骼评价方法综述](https://www.nist.gov/publications/evaluation-methods-and-measurement-challenges-industrial-exoskeletons)、[运动平滑度与 jerk](https://pmc.ncbi.nlm.nih.gov/articles/PMC4674971/)、[外骨骼执行器的扭矩误差与功耗评价](https://pmc.ncbi.nlm.nih.gov/articles/PMC7971410/)。

不要只追求最小稳定时间。过大的增益可能带来超调、振荡、力矩突变和饱和；对外骨骼而言还可能让使用者感到拉扯或“打架”。这里测的是理想仿真时间，不含真实传感器、滤波、通信、电机驱动和人体耦合延迟。

### Phase 1 输出

输出列分别是时间、关节角度、角速度和力矩。默认正力矩会让角度和速度先变成正值。随着杆件抬起，重力恢复力矩与阻尼开始抵消电机力矩，所以速度不必一直增加。

可以对比：

```bash
python experiments/001_single_joint_pd/run.py --torque 0
python experiments/001_single_joint_pd/run.py --torque 0.5
python experiments/001_single_joint_pd/run.py --torque -0.5
```

零力矩时，初始杆件位于竖直最低点，应基本保持不动；负力矩会产生相反方向的运动。
