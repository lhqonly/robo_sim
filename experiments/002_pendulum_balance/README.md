# Phase 3：膝关节摆杆与重力托举

## 这一课解决什么问题

Phase 1/2 的橙色杆主要用于学习关节和控制器。本实验把身体含义明确下来：

```text
固定大腿 → 膝关节 → 小腿 + 脚
```

模型从屈膝 `45°` 开始。0° 表示小腿自然垂下。教学参数为小腿 `3.0 kg`、脚 `0.8 kg`，膝电机上限 `±10 N·m`；它们是简化参数，不代表具体人体或医疗产品。

## 两组对照

被动下落：

```bash
python experiments/002_pendulum_balance/run.py \
  --mode passive --initial-deg 45 --duration 3
```

电机托举：

```bash
python experiments/002_pendulum_balance/run.py \
  --mode hold --initial-deg 45 --duration 3
```

打开 3D Viewer 与中文学习面板时，在命令后添加 `--view`。

## 应该看到什么

在 45°，MuJoCo 根据小腿、脚、重心和重力计算出保持姿态约需 `6.416 N·m`。

- `passive`：电机输出 `0 N·m`，小腿向 0° 落下并因惯性摆动。
- `hold`：电机实时提供约 `6.416 N·m`，小腿保持在 45°。

中文面板显示：

```text
保持姿态所需总力矩
= 膝电机承担
+ 尚需人体承担（概念量）
```

当前模型没有肌肉。“人体承担”不是仿真中真的施加了肌肉力，而是假设人想保持当前姿态时，电机没有提供的剩余部分。下一阶段进入外骨骼助力模型后，才会把人体和外骨骼分别建成明确的力矩来源。

## 为什么不是 PD 实验

本课只回答“重量由谁托住”。`hold` 直接补上模型重力矩，不负责从其他角度追踪到 45°。PD 负责纠正角度和速度误差；重力补偿负责承担已知重量。把两件事分开，更容易理解后续的人机共同出力。
