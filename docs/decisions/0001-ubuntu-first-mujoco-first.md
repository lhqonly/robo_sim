# ADR 0001：Ubuntu-first 与 MuJoCo-first

- 状态：Accepted
- 日期：2026-07-10

## 背景

项目目标是逐步理解人体下肢、外骨骼助力、控制与数据分析。当前学习者刚接触模型、动力学和训练，需要快速运行、容易观察、容易修改的最小实验，而不是一开始搭建完整机器人平台。

## 决策

1. 开发与文档以 Ubuntu 为第一环境，并保持 WSL2 兼容。
2. 仓库位于 WSL 的 Linux home，不使用 `/mnt/c` 作为工作目录。
3. 早期仿真使用 MuJoCo。
4. 学习顺序为单关节、PD 控制、摆杆、单腿、助力、简化人体、数据记录，之后才考虑 Gymnasium/RL、ROS2 或 Isaac Lab。

## 理由

- Ubuntu 与后续机器人、ROS2 和计算基础设施的常见运行环境一致。
- WSL home 可减少跨文件系统性能和权限问题。
- MuJoCo 安装较轻，能直接表达刚体、关节、执行器、接触和动力学。
- 简单模型能把控制问题与复杂资产、渲染和训练框架解耦，使实验结论更容易解释。

## 影响

- Phase 0 不安装 Isaac Sim/Isaac Lab、ROS2、PyTorch 或强化学习算法库。
- 初期模型不会追求真实人体几何与生物力学精度。
- 后续如果迁移到 Isaac Lab 或硬件接口，必须在新的 ADR 中说明触发条件、迁移边界和保留的验证基线。
